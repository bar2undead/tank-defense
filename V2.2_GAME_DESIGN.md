# Tank Defense V2.2 — implementation-ready game design

Status: design only; existing main branch remains untouched. Target: 10 stages, solo / AI teammate / two-player co-op, authoritative Node.js + ws server, five existing UI languages.

## Progression
- Bosses only on levels **2, 4, 6, 8, 10**, as final spawn of the wave. Remove previous boss triggers on levels 3/6/9.
- Level-2 boss must be smarter and stronger than old level-3 boss: prioritize threatening players or exposed base, dynamically navigate around obstacles, dodge approaching projectiles when possible, and vary attacks.
- Boss tier multipliers relative to new level-2 boss: **1.00, 1.40, 1.96, 2.744, 3.8416**. This is an overall threat budget, not a requirement to multiply every stat. Increase effective HP/damage/attack frequency/skills within this budget; avoid impossible encounters.
- Level 4: burst fire; level 6: call reinforcements; level 8: frost zone; level 10: combined skills. Telegraph special attacks and cap spawned adds.

## Ordinary enemy archetypes
- Normal: basic pressure, modest durability.
- Fast: quick movement, fragile.
- Heavy: high HP, slower movement.
- Sniper: long-range shots, repositions for clear firing lanes.
- Smart: obstacle-aware pathfinding, dodges shots, flanks player/base.
- Frost: within **2 grid tiles (80px)** applies **3s immobile** then **3s at 50% speed** to players; cooldown per frost tank to prevent permanent freeze; visible snowflake/status.
- Assault: short sprint toward exposed target with cooldown.
- All archetypes should have visually distinctive colors/shapes and meaningful behavior; enemies remain server-authoritative.

## Level generation
- Levels 1–4: existing fixed base and conventional spawn area.
- Levels 5–10: randomly choose valid base tile anywhere on map (not in impassable terrain or walls); enemy spawns random valid tiles across the map, not fixed at top.
- Guarantee spawn safety: clear a small base perimeter, avoid spawning on players, base or blocked tiles, enforce minimum spawn separation.
- Validate navigability/pathfinding between every enemy spawn and the base, and ensure player reachable locations. Retry random generation on failure; deterministic seed per room/level for consistency and debugging.
- AI teammate's defense target must use actual base coordinates, not hard-coded (660,660).

## Forest cover
- Double forest tile generation probability compared with existing V2.
- Draw forest canopy **after all tanks and tank nameplates/healthbars** so tanks are fully obscured. Keep bullets and VFX on top for readability.
- Forest tiles remain passable by tanks and projectiles; concealment is visual for player and enemy tanks alike.
- Use layered rendering: terrain -> walls/water/base -> items -> tanks -> tree canopy -> projectiles/effects -> HUD.

## Coins and upgrades
- Coins awarded for enemy kills, shared at room level; server owns balances and purchase validation.
- Shop appears between cleared stages (not during active combat). Host purchases shared upgrades: damage, fire rate, movement speed, base maximum HP.
- Initial pricing proposal: 100/200/300/400/500 coins for levels 1–5 of each upgrade; max level 5. Prices and economy require playtesting.
- Purchases persist across stages in the same room; restart resets currency and upgrades. No account persistence in V2.2.

## Difficulty
- Choose Easy / Normal / Hard before starting; room host controls selection, applies to both players and AI.
- Difficulty adjusts spawn rate, enemy durability, and damage, with conservative caps. Boss 40% stage scaling applies independently of selected difficulty.
- Show selected difficulty and current coins in HUD.

## Quality and regression criteria
1. Solo, AI teammate and two human players can complete all ten stages.
2. Boss appears exactly at levels 2/4/6/8/10; each boss has visible HP and escalating behavior.
3. Frost applies 60 server ticks immobilized + 60 ticks slowed at 20 ticks/sec; no indefinite stacking.
4. Levels 5–10 randomize base and spawns across repeated rooms; all generated layouts playable.
5. Forest density ~2x previous and completely hides tanks while inside foliage.
6. Shop cannot be bought during gameplay or by non-host; coin balances never negative; purchase changes synchronized.
7. Difficulty selection synchronized; browser auto-language + saved manual preference retained.
8. Existing projectile-v-projectile collision, powerups, rescue and Render startup still work.
9. Test syntax and gameplay simulation before merge; keep main branch unchanged until verified.

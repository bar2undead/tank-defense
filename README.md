# Tank Defense Online V2.4 — 保卫大本营

双人在线合作坦克大战，Node.js + ws，服务器权威判定，1280×720 (16:9) 宽屏，10 个关卡。

## 游戏版本与功能（V2.3）
- 10 个主题关卡：城市、森林、沙漠、雪地、湿地、工业区、峡谷、冰原、堡垒、终局。
- 普通、快速、重甲、狙击、智能、冰霜和突击敌人；第 2、4、6、8、10 关最后一名敌人为 Boss（相邻 Boss 强度目标递增 40%），血量条。
- 双发炮弹、快速射击、穿甲弹、伤害升级（升级道具重复拾取可提高等级）。
- 砖墙两次命中摧毁，钢墙不可破坏，树林允许穿行和穿弹，成片树林以前景图层完全遮挡坦克，河流不可通行。
- 随机道具：护盾、基地修复、冻结敌人、清场炸弹、武器升级、速射、穿甲、治疗。
- 双人倒地救援：队友靠近并按住 E / 救援键约 1.75 秒。部分道具双方共享。
- 敌对炮弹在服务器同一帧按线段相对运动检测，碰撞时互相抵消。
- 自动按浏览器首选语言显示：英文、简体中文、繁体中文、日文、法文；右上角可手动切换，选择保存在本机浏览器。
- Web Audio 合成简易射击、爆炸、碰撞音效（首次操作后激活）。

## 本地运行
安装 Node.js 18+，在包含 `server.js`、`index.html`、`client.js`、`package.json` 的目录执行：

```bash
npm install
npm start
```

访问 http://localhost:3000 。两个浏览器标签页可在本机测试房间。

## 更新已有 GitHub / Render
1. 在 GitHub 仓库 `bar2undead/tank-defense` 的根目录上传 ZIP 解压出的 **5 个文件**（不要上传 ZIP 本身，也不要多套一层文件夹）。
2. 覆盖原有同名文件，Commit changes。
3. Render 现有 Web Service 保持 Build Command=`npm install`、Start Command=`npm start`、Root Directory 留空。等待最新部署状态 Live。
4. 所有玩家按 Ctrl+Shift+R 强制刷新，并重新创建房间。旧房间会随部署重启而清空。

**注意**：不需要 `public/` 目录。`server.js` 已直接从项目根目录提供 `index.html` 和 `client.js`，避免 Not found。

## 操作
- 移动：WASD / 方向键
- 开炮：Space / J
- 救援：靠近倒地队友，按住 E（手机按住救援）
- 房主：下一关、重新开始

## 限制
- 免费 Render 服务可能休眠，房间在重启时丢失；没有数据库持久化。
- 可选择 Easy / Normal / Hard 三档难度；没有账户或全局排行榜。
- 服务器负责所有物理碰撞、伤害、道具、Boss 和炮弹抵消。


## V2.1 — 单人模式与 AI 队友

- **单人游戏 / Play solo**：不需要第二位玩家，点击后立即开始，独自守卫基地。
- **AI 队友 / Play with AI**：点击后立即开始，服务器控制第二辆蓝色坦克，自动移动、攻击敌人，并在玩家倒地时靠近救援。AI 是本地规则式游戏 AI，不需要 OpenAI API、密钥或额外费用。
- **创建房间 / 加入房间**：保留原来的双人在线联机功能。
- 单人及 AI 模式均可点击「下一关」「重新开始」。刷新网页会结束当前房间，进度不保存。
- 所有模式继续支持自动语言识别及手动切换。
- 部署：将本 ZIP 的 5 个文件直接上传到原 GitHub 仓库根目录，覆盖同名文件；Render 自动部署。


## V2.2 功能
- 关卡 2、4、6、8、10 出现 Boss，后一个 Boss 相对前一个的强度目标增加 40%，具备更主动的移动、躲避与特殊攻击。
- 新增智能、冰霜、突击坦克；冰霜坦克靠近玩家两格内使其冰冻 3 秒，随后减速 3 秒。
- 第 5 关起基地位置和敌人出生位置随机化。
- 金币与关卡间升级商店：攻击力、射速、速度、基地生命；三种难度选择。
- 树林在坦克上方绘制，实现视觉隐藏。

## V2.3 功能
- README 同步更新至当前游戏版本。
- Rescue / 救援按钮移至游戏画面左上方、基地信息栏下方；键盘 E 仍可救援。
- 游戏画面右上角增加全屏切换按钮；也可使用 Esc 退出全屏（浏览器支持时）。
- 树林密度进一步提高，增加大片连在一起的树林区域。
- 开始游戏时播放约 7 秒原创复古 8-bit 坦克风格开场音乐；由用户点击启动，符合浏览器音频播放限制。
- 每位玩家初始 3 HP，游戏顶部基地生命值旁显示 P1/P2 爱心生命值。
- 坦克之间加入服务器端碰撞分离，减少重叠，接触时轻微弹开。

## V2.3 测试建议
- 单人、AI 队友、双人联机各测试至少一局，特别检查碰撞与救援距离。
- 测试树林中完全隐藏坦克、全屏后手机/桌面按钮位置、音频只在点击开始后播放。
- 检查随机地图第 5–10 关的基地可达性及 Boss 出现关卡。


## V2.4 — 最多九人合作、房间大厅、暂停与跳关
- 创建房间后不会自动开局：玩家输入 1–8 个英文字母的名字，分享房间号，等待最多 8 名队友加入（房主 + 8 名队友，共 9 人），房主点击 **Start Game / 开始游戏**。
- 单人游戏和 AI 队友仍可直接开始；已有多人房间由房主开始。
- 玩家名字显示在坦克上方；重复名字会自动添加数字后缀。
- 房主可在游戏进行中点击 **Next level / 下一关** 强制跳关，或点击 **Pause / Resume** 暂停、恢复。暂停冻结服务器的游戏模拟。
- 任意队友倒地后，其他玩家客户端每 3 秒播放一段原创危险提示旋律，直到队友获救或游戏结束。
- 每关树林密度随机为 V2.3 原有树林的 20%–80%，保留连片森林的布局。
- 每位玩家初始 3 HP，保留碰撞分离、救援、全屏、原创开场音乐和金币升级。
- 九人联机、多人同时倒地救援、随机地图和 Boss 战仍需实机压力测试；当前没有持久化进度。
